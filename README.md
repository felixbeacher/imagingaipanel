# Medical Imaging AI & Health Macro Dashboard

An executive intelligence dashboard designed to monitor industry news, regulatory trends, macroeconomic indicators, and market adoption rates in medical imaging AI to support strategic investment decisions.

## Overview

The **Imaging AI Panel** provides a single-page, real-time analytics interface that bridges macroeconomic health data with targeted medical technology metrics. It tracks regulatory clearances (FDA/CE), venture capital inflows, radiology workforce deficits, and modality breakdowns alongside automated industry headlines.

### Key Features

* **Interactive Region Filter:** Dynamically update line graphs, modality distribution charts, and key sector metrics by global region (Global, North America, Europe, Asia, Middle East, South America).
* **Macroeconomic & Sector Tickers:** High-level visibility into key indices, including UK Base Rate, Healthcare Inflation, MedTech VC Funding, NHS Imaging Backlog, and Cloud Compute Inference Costs.
* **Automated News Feed:** Scripted updates using Python to pull the latest relevant sector headlines directly into the interface.
* **Responsive Visualisations:** Built using Chart.js for smooth client-side rendering across desktop and mobile devices.
